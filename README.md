## What is TechSites Builder?

TechSites Builder is a **next-generation site construction platform** built to replace WordPress, Hostinger, and AI site generators simultaneously. It generates ultra-modern commercial websites from a 6x6x6 Design Matrix — 46,656 unique structural combinations — served at the edge via Cloudflare Workers with sub-10ms response times.

### Why it replaces existing solutions

| Problem with current tools | TechSites solution |
|----------------------------|-------------------|
| WordPress: 50,000+ plugins, 87% of hacked sites | **Zero plugins.** Pure HTML/CSS/JS, no attack surface |
| Hostinger/Wix: generic templates, visually identical sites | **6x6x6 Matrix:** 46,656 unique combinations per license key |
| AI generators: hallucinated copy, no brand voice | **APEX CORE integration:** real briefing → real copy |
| Slow sites: 3-8s load time, heavy frameworks | **Cloudflare edge:** static HTML served in <10ms |
| Hard to edit: requires developer for every change | **Built-in WYSIWYG:** inline editing, no backend |
| One codebase = one vulnerability | **Isolated per client:** no shared PHP, no shared DB |

## Core Concepts

### 1. 6x6x6 Design Matrix
Every license key deterministically maps to a unique combination of 6 HTML blocks:

```
licenseKey → getSiteMatrixIndices() → [2, 5, 1, 4, 0, 3]
                                       ↓  ↓  ↓  ↓  ↓  ↓
                                      Menu Home About HowTo Contact Footer
                                      (6 variants each = 6⁶ = 46,656 combos)
```

See [`docs/matrix-system.md`](docs/matrix-system.md) for full specification.

### 2. Cross-Matrix Design Tokens
Each site niche has a scientifically validated CSS token set based on international brand psychology standards:

```css
/* Health & Wellness niche */
--color-primary: #2ECC71;
--color-accent: #1ABC9C;
--font-headers: 'Montserrat', sans-serif;
--radius-global: 12px;
--shadow-depth: 0 4px 20px rgba(46,204,113,0.15);
```

See [`docs/design-tokens.md`](docs/design-tokens.md) for all 12 niches.

### 3. Questions Card Onboarding
3 multiple-choice questions + 1 short description → APEX CORE generates full SEO copy for every section in < 30 seconds.

### 4. Built-in WYSIWYG Editor
Every site includes a floating inline editor. Clients edit text, images, and colors without any backend. State persists in Cloudflare KV at the edge.

### 5. Zero-Framework HTML
Sites are pure HTML + CSS custom properties + minimal vanilla JS. No React, no Vue, no build step. This means:
- **No CVEs** from npm packages
- **No hydration** delays
- **No framework lock-in**
- **Easy to fork** for white-label

## Quick Start — Run Locally

The hub dashboard is a Cloudflare Worker — use Wrangler for local dev:

```bash
# Install Wrangler
npm install -g wrangler

# Authenticate
wrangler login

# Start local hub (uses remote KV in preview mode)
cd workers/techsites-hub
wrangler dev --remote

# Start ts-builder-proxy locally
cd workers/ts-builder-proxy
wrangler dev
```

For the WYSIWYG editor, see [`docs/wysiwyg-editor.md`](docs/wysiwyg-editor.md).

## Provisioning a New Client

```bash
./scripts/new-client.sh \
  --domain "client-name.techsites.ai" \
  --niche "food-beverage" \
  --plan "pro" \
  --license "TS-XXXX-XXXX-XXXX"

# This script:
# 1. Generates matrix seed from license key
# 2. Creates KV entry: { domain, seed, tokens, content: {} }
# 3. Configures DNS CNAME → Hub Worker
# 4. Registers client in Hub dashboard
# 5. Sends welcome email with WYSIWYG editor link
```
